# Better Prayer Stations — Faith Probe0.7.0

Research-only square/grid and preview feedback candidate. Canonical version: Plugin.cs. Exact frozen source, DLL hash and installed state: docs/TEST_BUILD_LOG.md. Not a production release; real-game acceptance pending. No passive station-quality bonus, final artwork, final balance or action cap.

## Короткий сценарий

1. Загрузите игру. Откройте занятую могилу с красным черепком и назначьте **A**. Если C/L/N нулевые, нажмите **«Подготовить тест переноса: C1/L1 БЕЗ оплаты»**. Это бесплатные сохраняемые диагностические вложения; тело/органы/украшения не меняются. Для этой проверки покупать улучшения не нужно.
2. Кнопки **«Материалы на деревянную молельню»** и **«Материалы на каменную молельню»** выдают полный набор на одну постройку за каждый клик. Освободите три ячейки основного инвентаря. Проверьте обе кнопки; повторный клик выдаёт ещё один набор. Деньги/вера не расходуются. Технологии, допустимые места постройки и обычная работа строителя остаются нативными. Предметы обычные и сохраняются при сохранении игры; очистка могил их не удаляет.
3. Через обычное строительство выберите доступное место для молельни рядом с A. Включите **«Показывать тестовую область»**. Дерево: квадрат18×18 маленьких строительных клеток; камень:24×24. Это временные размеры для сравнения. Жёлтая область должна двигаться по сетке. Могилы с центром внутри неё подсвечиваются зелёным целиком; край могилы может выступать наружу. Во время предпросмотра у A остаётся исходное число, справа — зелёное **+1** либо красноватое **-1** (фактическая разница может быть иной). Нулевую разницу не пишем. Если A уже покрыта другой молельней, новая область может не менять её качество: это правильный нулевой результат.
4. Отмените обычное строительство: разница исчезает, исходное качество сохраняется. Повторите, подтвердите строительный проект и затем достройте. Между подтверждением и достройкой проект ещё не даёт эффекта. После завершения меняется обычный итог, временная разница исчезает. Деревянную/каменную область можно сравнить в строительном предпросмотре; не требуется строить обе ради сравнения.
5. В обычной игре подойдите к готовой молельне: голубой квадрат и зелёные могилы появляются возле ближайшей молельни (тестовая дистанция подхода128 единиц/4 маленьких клетки). Отойдите — исчезают. В этом режиме над могилой остаётся текущий итог, без разложения на основу и бонус.
6. Дополнительно, если Move Objects установлен: выберите готовую молельню, уведите предпросмотр за A и обратно, отмените; затем подтвердите перенос наружу и обратно. Старое место источника не должно продолжать покрывать A. Во время предпросмотра число остаётся исходным плюс подписанная разница; после подтверждения/отмены остаётся обычный актуальный итог. Счётчик готовых молелен не растёт.
7. Нажмите **«Записать состояние обеих могил»**, затем **«Очистить ОБЕ могилы и завершить тест»** (работает и с одной A). Сохраните обычным способом, если хотите сохранить постройки/полученные материалы. F8 скрывает диагностическую панель и область. Свежий журнал агент прочитает локально.

Сценарий обычного строительства не требует использования Move Objects, но чистая среда без его DLL пока отдельно не принята. Если нет свободного разрешённого игрой места или технологии, не нужно сносить кладбище ради теста: сообщите, какой шаг оказался недоступен. Кнопки не разблокируют строительство. Загрузку, оплату и анатомию повторно проверять в этой узкой итерации не требуется.

## Mechanism, invariants and evidence limits

GridFootprint caches the single native layer23 BoxCollider2D per current WGO definition, independently of sprite bounds/disabled visual renderers. Actual TransformPoint of offset/size produces XY extents;32-unit grid cell centers intersecting the native28.8-unit occupancy-check box define the ground footprint. Bounding rectangle center drives both coverage and highlight. Cached local collider geometry is transformed at its actual current position, not copied absolute _cells from the old source. Non-axis-aligned/multiple unsupported boxes reject diagnostic geometry. FOOTPRINT/STATION_OBJECT compare this rectangle against native _cells where populated; native-empty cells are explicitly inconclusive. Live alignment and agreement are required before promoting the mechanism.

Wood half-side288 (9 small cells), stone384 (12); inclusive center-point membership. These are diagnostic dimensions, not adopted balance. All real grave refs are collected once at Recover and through verified WorldMap.OnAddNewWGO (also called by SetObject), pruned from cached refs; no recurring world discovery. Highlight covers real grave footprints. Faith effects/delta observations remain bounded to the two assigned graves. Only nearest approached station or current preview is outlined. Screen GUI uses existing white texture and restores matrix/color, creates no world assets/colliders/input handlers. Highlight rendering remains a live visual test.

New construction placeholders pray_stand_wd_place/stn_place are eligible only while floating; committed unfinished projects are not built stations. SetObject -> OnAddNewWGO observes native completion. Existing completed source is replaced by preview; no new station counted for moving it. Stop(false) still does not prove final external-move settlement. No cap/payment/save schema changed.

Before Begin, capture each marked grave's actual committed quality and native text with only preview replacement disabled; all actual station effects remain included. Baseline stays frozen during cursor movement. Postfix of native GetQualityWidgetData changes only marked preview quality-widget text to frozen original plus signed delta; no expected/fake final quality is written. Native build quality_k scaling is respected. Native quality setter/container/redraw path is retained, with changed-value cache invalidated at begin/end. Physical hashing/logging happens only on changed badge, not every frame. At end discard baselines; native actual value wins. Zero difference has no suffix. Rich-text rendering/centering/clipping require the user observation; native widget may center the combined line (baseline digit need not remain at identical screen X).

Offline gates: existing160 native skull-oracle and2700 native getter cases; payment/role/serializer/native-zone fixtures; compiled StationSet/lazy exact Move adapter/native badge route; square boundary/corners/tier distinction; frozen number/icon with positive/negative/zero/returned deltas; grid footprint fixture/translation. No offline test proves Unity scene, actual native collider cells, construction completion, proximity feedback or rendered text.
