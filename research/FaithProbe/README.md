## Короткий тест — одна молельня, одна могила, без расхода веры

1. Откройте занятую могилу с красным черепком и назначьте её A. При нулевых тестовых вложениях нажмите **«Подготовить тест переноса: C1/L1 БЕЗ оплаты»**. Дождитесь проверки. Это диагностическая подготовка, не покупка: вера не списывается, тело и украшения не меняются. Если вложения уже есть, их можно использовать без подготовки.
2. Закройте могилу. Убедитесь, что включено **«Показывать тестовый радиус»**. Голубой круг показывает рабочий радиус построенной молельни, жёлтый — предполагаемый радиус при переносе. Радиус3 клетки, отсчёт от нативного начала объекта; это тестовая геометрия, не баланс. Счётчик «Построенные молельни» должен соответствовать действительным постройкам.
3. Через Move Objects выберите молельню и поводите предпросмотр так, чтобы могила выходила из круга и возвращалась. Старый голубой круг этой молельни заменяется одним жёлтым; надпись говорит о переносе, не о новой молельне. Число непосредственно НАД могилой должно меняться уже при движении жёлтого круга, без выхода из режима переноса. Рейтинг/строка активности должны показывать результат предполагаемой позиции, а число построенных молелен не растёт. Не переносите саму могилу в этом сценарии.
4. Уведите предпросмотр так, чтобы могила оказалась вне радиуса, затем **отмените перенос обычной кнопкой игры**. Исходная молельня остаётся на месте; возвращается её голубой круг и исходная активность могилы. Проверьте также число непосредственно над могилой, оставаясь в режиме переноса. Повторите выбор и отмену ещё2–3 раза: счётчик должен оставаться прежним.
5. Снова перенесите молельню, теперь **подтвердите** позицию вне радиуса могилы. Жёлтый круг сменится голубым в новой точке, количество молелен не меняется, улучшения могилы неактивны. Подтверждённым переносом верните молельню обратно: эффекты снова работают, C/L/N сохраняются. По желанию откройте могилу и нажмите повторную проверку рейтинга/шкалы.
6. Нажмите **«Очистить ОБЕ могилы и завершить тест»** (действует и для одной A), затем сохраните игру обычным способом. Улучшения и диагностические роли очищаются, реальный подтверждённый перенос молельни остаётся. F8 скрывает панель вместе с кругами; отдельный переключатель скрывает только радиус.

Если круг не виден, сообщите об этом вместе с результатом переноса: экранный контур ещё не принят в реальной игре. Задержка числа над могилой теперь является ошибкой этого теста: проверяйте именно его, вместе с диагностической активностью. Этот тест не требует проверки зоны, B, оплаты или загрузки. Пара после загрузки остаётся отдельным ещё не записанным сценарием.
