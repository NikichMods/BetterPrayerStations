# Menu Probe 0.4.0 — оплата вместимости верой

Покупка +1 вместимости теперь действительно списывает веру из инвентаря и сумок игрока. Общий ряд первых десяти цен: **1, 2, 3, 4, 6, 9, 12, 15, 18, 21**. Цена зависит от общей купленной вместимости в этом сохранении, а не от выбранной молельни. После десяти покупок действует прежний предел прототипа; дальнейшие цены не выбраны.

Уже полученная тестовая вместимость сохраняется без доплаты: при6 местах следующая покупка стоит12 веры. При нехватке веры или поддержки покупка недоступна. Постановка/удаление точек бесплатны; снос молелен и удаление точек не сбрасывают цену и не возвращают веру. Порядок активации и эффект0.3.1 сохранены. Визуал остаётся техническим.

В панели **F8** добавлены кнопки:

- «Материалы: деревянная молельня» — комплект по текущему игровому рецепту на одну постройку.
- «Материалы: каменная молельня» — такой же комплект для каменной.
- «Добавить +50 веры (тест)» — можно нажимать повторно при наличии места.

Для выдачи закройте строительные/другие большие окна и выйдите из режима постановки точек. Материалы не открывают технологии и не строят молельни автоматически. При нехватке места выдача отказывается без добавления; если возникнет ошибка частичной выдачи, дальнейшая выдача отключается до перезапуска, чтобы не повторять её вслепую. Выданные предметы настоящие и попадут в обычное сохранение.

## Короткая проверка

1. Загрузите тестовое сохранение. При прежних6 местах должна отображаться цена12. Если поддержка только5, постройте вторую деревянную или готовую каменную молельню; материалы доступны в F8.
2. Сверьте количество веры, при необходимости добавьте50 через F8. Купите одно место: вместимость6->7, вера уменьшается ровно на12, следующая цена15. Нажмите покупку только один раз.
3. Откройте другую готовую молельню: следующая цена должна остаться15. При покупке там вместимость7->8, списание15, следующая цена18.
4. Сохранитесь обычным способом и загрузитесь снова: вместимость, точки, остаток веры и следующая цена должны восстановиться. Достаточно одной точки на могиле для короткой проверки сохранённого эффекта; полный тест поддержки повторять не требуется.
5. Для проверки нехватки переложите веру из инвентаря **и сумок** в сундук, оставив меньше следующей цены. Карточка покупки должна стать недоступной; вместимость не меняется. Затем верните веру или добавьте50 через F8 — покупка должна снова стать доступной при достаточной поддержке.
6. Проверьте обе кнопки материалов и обычную постройку молелен. Названия/количества выданного и точные списания агент сверит по логу. Не нужно считать порядок вручную.

Обычное сохранение игры пишет на диск и покупки, и выданные ресурсы. «Очистить точки и покупки» — диагностический сброс вместимости/позиций/ряда цен **без возврата уже потраченной веры**; для текущего теста он не нужен. Очистка закрепляется обычным сохранением. Для удаления только одной точки используйте «Убрать свет».

Точное состояние сборки и принятые границы прежних тестов: docs/TEST_BUILD_LOG.md. Готовность транзакции и выдачи: docs/GLOBAL_CAPACITY_PAYMENT.md. Автоматические проверки не заменяют проверку реального списания в игре.
