# Menu Probe 0.1.0 — readiness and method

Research-only, user-authorized native three-card management/temporary point editor. Existing exact static evidence: docs/BUILD_MENU_RESEARCH.md. Real UI layout, interaction and camera/input cleanup require a live prototype; repeating a static scan or an older faith probe cannot prove them.

READY for this bounded session-only UI experiment, not production acceptance: native CraftGUI + CraftInterface own rendering/availability/dispatch; transient additional_crafts supply three distinct actions. Native station definition inputs are temporarily projected to Builder/explicit graveyard zone and restored on load/unload/cleanup. Original bodies, rating, faith, money, inventory and serialized state are never written. Native BuildGrid availability/zone selection and camera framing are reused; physical occupancy is suppressed only synchronously while our grid is being painted, never for an actual build. Our exclusive editor handler bypasses native building/removal/refund routines; marker selection is local point data only.

Question matrix: open either completed station -> three native cards/counts; buy -> local P+1/unchanged faith+money; place on ground/grave -> local snapped32-unit point only; remove -> P unchanged/new placement newest; capacity loss -> newest placements dormant; reload -> all local state reset; cancel/cleanup -> camera/control/grid/native controller restored. Mouse and native gamepad action keys require installed observation. No native floating WGO is created. No payment, save/load persistence, quality conversion or final light art is being tested.

Initial support uses actual completed station count5/10 in the cemetery. Single registry scan at game-ready; native add event plus bounded cached-list refresh, no recurring world scan. Diagnostic purchase bound is ten slots, exactly the adopted first-ten trial prices displayed only; no invented continuation. MainGame current-player/save identity is checked before opening/actions. A visible small test panel provides reset/cleanup and a station-open shortcut if the hint route fails; shortcut use must not be reported as proof of native interaction.

Build gate: SDK6.0.406 Roslyn, local exact host references, warning-as-error; executable tests on the actual compiled state policy and pinned native/custom-dispatch structure. Fail closed with session cleanup on unexpected errors. Freeze clean committed source, numbered0.1.0 artifact and hash before local install. Keep prior probes backed up outside loader path and inactive during this isolated test. No stable/main/release promotion.
